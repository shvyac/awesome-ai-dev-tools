## ツール

- [WARP CLI](https://developers.cloudflare.com/warp-client/) - Cloudflare WARP クライアントと `warp-cli` コマンドライン。1.1.1.1 経由の安全で高速な接続。macOS / Windows / Linux / iOS / Android 対応。 *(クローズドソース)*
- [Factory AI](https://factory.com/) - エンタープライズ向け AI コーディングエージェント (Droids)。デスクトップ・ターミナル・Web・CLI から利用でき、モデル非依存。 *(クローズドソース)*
- [CodeRabbit](https://www.coderabbit.ai/) - プルリクエスト向け AI コードレビュー。トリアージ、要約、セキュリティチェックに対応し、GitHub / GitLab で利用可能。 *(クローズドソース)*
- [Git Tower](https://www.git-tower.com/) - Mac / Windows 向けの高機能 Git クライアント。 *(クローズドソース)*
- [Cursor](https://cursor.com/) - AI コーディングエージェント / エディタ。デスクトップ・CLI・クラウドエージェントを提供。 *(クローズドソース)*
