## ツール

- [WARP CLI](https://developers.cloudflare.com/warp-client/) - Cloudflare WARP クライアントと `warp-cli` コマンドライン。1.1.1.1 経由の安全で高速な接続。macOS / Windows / Linux / iOS / Android 対応。 *(クローズドソース)*
- [Factory AI](https://factory.ai/) - エンタープライズ向け AI コーディングエージェント (Droids)。デスクトップ・ターミナル・Web・CLI から利用でき、モデル非依存。 *(クローズドソース)*
- [Claude Code](https://code.claude.com/docs/en/overview) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/anthropics/claude-code?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F20-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/anthropics/claude-code?style=flat) - Anthropic のエージェント型コーディングツール。ターミナル・IDE・デスクトップ・Web で動作し、コード編集、コマンド実行、git 操作を行う。MCP・スキル・プラグインに対応。 *(プロプライエタリ。GitHub リポジトリは Issue とプラグイン用)* ([GitHub](https://github.com/anthropics/claude-code))
- [Codex CLI](https://developers.openai.com/codex) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/openai/codex?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F20-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/openai/codex?style=flat) - OpenAI の軽量コーディングエージェント。ターミナルで動作 (Rust 製)。サンドボックス実行、MCP 対応、クラウドタスクを備える。 *(オープンソース、Apache-2.0)* ([GitHub](https://github.com/openai/codex))
- [Gemini CLI](https://geminicli.com/) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/google-gemini/gemini-cli?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F19-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/google-gemini/gemini-cli?style=flat) - Google のオープンソース AI エージェント。Gemini をターミナルで利用でき、組み込みツールと MCP 対応を備える。 *(オープンソース、Apache-2.0)* ([GitHub](https://github.com/google-gemini/gemini-cli))
- [OpenCode](https://opencode.ai/) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/anomalyco/opencode?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F17-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/anomalyco/opencode?style=flat) - オープンソースでプロバイダ非依存のコーディングエージェント。ターミナル UI・デスクトップアプリ・IDE 連携を提供し、ローカルモデルを含む多数のモデルプロバイダに対応。 *(オープンソース、MIT)* ([GitHub](https://github.com/anomalyco/opencode))
- [CodeRabbit](https://www.coderabbit.ai/) - プルリクエスト向け AI コードレビュー。トリアージ、要約、セキュリティチェックに対応し、GitHub / GitLab で利用可能。 *(クローズドソース)*
- [Git Tower](https://www.git-tower.com/) - Mac / Windows 向けの高機能 Git クライアント。 *(クローズドソース)*
- [Cursor](https://cursor.com/) - AI コーディングエージェント / エディタ。デスクトップ・CLI・クラウドエージェントを提供。 *(クローズドソース)*
