## Tools

- [WARP CLI](https://developers.cloudflare.com/warp-client/) - Cloudflare WARP client with the `warp-cli` command line: secure, fast connectivity via 1.1.1.1 for macOS, Windows, Linux, iOS, and Android. *(closed source)*
- [Factory AI](https://factory.ai/) - AI coding agents (Droids) for the enterprise; works from desktop, terminal, web, and CLI, and is model agnostic. *(closed source)*
- [Claude Code](https://code.claude.com/docs/en/overview) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/anthropics/claude-code?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F20-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/anthropics/claude-code?style=flat) - Anthropic's agentic coding tool for the terminal, IDEs, desktop, and web: edits code, runs commands, handles git workflows, and supports MCP, skills, and plugins. *(proprietary; the GitHub repo hosts issues and plugins)* ([GitHub](https://github.com/anthropics/claude-code))
- [Codex CLI](https://developers.openai.com/codex) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/openai/codex?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F20-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/openai/codex?style=flat) - OpenAI's lightweight coding agent that runs in your terminal (Rust), with sandboxed execution, MCP support, and cloud tasks. *(open source, Apache-2.0)* ([GitHub](https://github.com/openai/codex))
- [Gemini CLI](https://geminicli.com/) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/google-gemini/gemini-cli?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F19-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/google-gemini/gemini-cli?style=flat) - Google's open-source AI agent that brings Gemini into the terminal, with built-in tools and MCP support. *(open source, Apache-2.0)* ([GitHub](https://github.com/google-gemini/gemini-cli))
- [OpenCode](https://opencode.ai/) ![New](https://img.shields.io/badge/-NEW-red?style=flat) ![GitHub stars](https://img.shields.io/github/stars/anomalyco/opencode?style=flat&label=%E2%AD%90) ![Release date](https://img.shields.io/badge/release-2026%2F11%2F17-blue?style=flat) ![Last commit](https://img.shields.io/github/last-commit/anomalyco/opencode?style=flat) - Open-source, provider-agnostic coding agent with a terminal UI, desktop app, and IDE integrations; works with many model providers, including local models. *(open source, MIT)* ([GitHub](https://github.com/anomalyco/opencode))
- [CodeRabbit](https://www.coderabbit.ai/) - AI code review for pull requests: triage, summaries, security checks; works with GitHub and GitLab. *(closed source)*
- [Git Tower](https://www.git-tower.com/) - Powerful Git client for Mac and Windows. *(closed source)*
- [Cursor](https://cursor.com/) - AI coding agent and editor with desktop, CLI, and cloud agents. *(closed source)*
